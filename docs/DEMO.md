# Two-minute demo

**0:00–0:15 — The question**

“This is Faultline. It helps me find the assumption that could change a decision. I’m choosing what to build next with six hours a week. These are three plausible options.”

Open the default example. If another decision is open, use My notebook → Open the example.

**0:15–0:35 — The tradeoff**

“I care about reaching a first user, enjoying the work, learning, and keeping costs low. These weights add to 100%. The extension leads at 7.75, but the workshop is close at 7.55.”

Point to the current ranking and the weights. Explain that scores run from 0 to 10 and higher means better.

**0:35–1:00 — Find the fault line**

“The useful part is the hinge. If enjoyment rises above 34.4%, the workshop overtakes the extension. That’s only about 4.4 percentage points from my current assumptions.”

Open Stress test, select Enjoyment, drag to 40%, and point to the lines crossing. Click Use these weights.

**1:00–1:20 — Admit what’s uncertain**

“I don’t know whether I’ll actually enjoy running a workshop. The orange ± mark treats that score as a range. These ranges overlap; that tells me what to investigate, not what will happen.”

Return to Score the options. Toggle the uncertainty mark on the workshop’s Enjoyment score. The interval updates immediately.

**1:20–1:45 — Keep the reasoning**

Open Decision brief. Add: “Run one workshop with five people before building a course.”

“The model misses real constraints, so I keep those alongside the numbers. I can save this to my notebook and come back when I learn something.”

Save. Open My notebook and reopen the decision. With a connected backend, show sign-in and the private notebook; otherwise identify the browser-only mode explicitly.

**1:45–2:00 — Take it with you**

Download the Markdown brief.

“The export contains the actual inputs and the tipping point. No opaque AI recommendation. It’s a small model I can inspect, challenge, and change.”
